# 大学模拟器

一款成长类**文字互动游戏**（华南理工大学背景）：大学四年没有标准答案，成功、遗憾、妥协、重启皆是成长。

- 五项属性：智力 / 社交 / 健康 / 精力 / 金钱
- 大一 ~ 大四主线 + 随机事件 + 后台身份标签
- 9 种结局（退学 / 透支迷失 / 圆满 / 遗憾 / 平凡）
- 16 个成就，LocalStorage 自动存档

## 如何玩

- **在线**：https://Cjw33.github.io/university-simulator/
- **本地**：下载后双击 `index.html` 即可（离线可玩）

## 技术

单页 HTML + CSS/JS，像素风 UI（Zpix 字体），图片为豆包样稿图。
